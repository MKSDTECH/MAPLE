# Maple3D
## Asset library for Rhino

Maple3D is a beta application developed by MKS DTECH that keeps a studio's blocks, materials and Grasshopper scripts in one versioned library, in a Rhino panel and on the web.

Key Features

- Versioned library: every block, material and script keeps its versions and previews.

- Rhino panel: search the library, insert blocks, apply materials and open scripts without leaving Rhino.

- Publish from this file: send the open model's blocks and materials to the library.

- Up-to-date models: see which placed blocks are behind the library and update them in place.

- Studio workspaces: a shared library with roles for each studio, and a Personal workspace for everyone.

Requirements: Rhino 8 SR9 or later on Windows or Mac, and a Maple3D account.
